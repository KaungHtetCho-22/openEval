# Examples

All example scripts live in `openeval/examples/`.

1. `01_basic_qa.py` — basic Q&A eval (no API key needed)
2. `02_openai_eval.py` — OpenAI eval + HTML report (uses `OPENAI_API_KEY` if set)
3. `03_compare_models.py` — compare two models with `batch_run` + `ComparisonTable`
4. `04_rag_eval.py` — evaluate a RAG pipeline
5. `05_chatbot_eval.py` — evaluate multi-turn chatbot behavior
6. `06_code_eval.py` — evaluate code generation
7. `07_custom_scorer.py` — write custom scorers from scratch
8. `08_cicd_integration.py` — CI/CD integration (pytest plugin + GitHub Action)
