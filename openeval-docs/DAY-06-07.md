## Step 2 — cli.py

Ask Claude: **"Write openeval/cli.py — a typer CLI with a `run` command"**

Tell Claude the `run` command signature:
```
openeval run --dataset path/to/data.jsonl --model ollama:llama3.2 --suite hallucination --threshold 0.7
```

Options:
- `--dataset` / `-d`: path to CSV or JSONL file
- `--suite` / `-s`: name of built-in suite (hallucination, factuality, instruction_following)
- `--model` / `-m`: model string like `openai:gpt-4o`, `anthropic:claude-sonnet-4-20250514`, `ollama:llama3.2`
- `--threshold` / `-t`: pass threshold float, default 0.7
- `--output` / `-o`: optional path to save HTML report

Model string parsing:
- `openai:gpt-4o` → use openai_adapter with model="gpt-4o"
- `anthropic:claude-sonnet-4-20250514` → use anthropic_adapter
- `ollama:llama3.2` → use ollama_adapter with model="llama3.2"

# DAY 7 — pytest Plugin

## Why this matters
The pytest plugin is the silent growth driver. Any project with tests can add OpenEval evals to their test suite in 3 lines. No new tool to learn. Just pytest.

---

## Step 6 — pytest plugin folder

Create:
```

├── __init__.py
└── plugin.py
```

---

## Step 7 — plugin.py

Ask Claude: **"Write pytest_openeval/plugin.py — a pytest plugin for OpenEval"**

Tell Claude what it needs:
- Register as a pytest plugin via `entry_points` in pyproject.toml
- Add a `@pytest.mark.eval` marker
- Add an `eval_model` fixture that reads `--eval-model` CLI option (e.g. `pytest --eval-model ollama:llama3.2`)
- Provide an `openeval_run` fixture that wraps the `run()` function
- Tests marked with `@pytest.mark.eval` can use these fixtures

Example usage people should be able to write:
```python
# test_my_model.py
import pytest

@pytest.mark.eval
def test_factuality(openeval_run, eval_model):
    from openeval.suites import factuality
    summary = factuality.run(eval_model)
    assert summary.pass_rate >= 0.8, f"Factuality pass rate too low: {summary.pass_rate:.0%}"

@pytest.mark.eval
def test_custom(openeval_run, eval_model):
    from openeval import EvalCase
    from openeval.scorers import contains
    cases = [EvalCase(input="Say hello", expected_output="hello")]
    summary = openeval_run(eval_model, cases, {"contains": contains})
    assert summary.pass_rate == 1.0
```
