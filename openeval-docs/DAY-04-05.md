# DAY 4 — Dataset Loaders

## Step 1 — dataset.py

Ask Claude: **"Write openeval/dataset.py with CSV and JSONL dataset loaders"**

Tell Claude the functions needed:
- `from_csv(path, input_col="input", output_col="expected_output") -> list[EvalCase]`
- `from_jsonl(path) -> list[EvalCase]` — each line is `{"input": "...", "expected_output": "..."}`
- `from_list(data: list[dict]) -> list[EvalCase]` — convenience wrapper
- All should return `list[EvalCase]`
- Handle missing `expected_output` gracefully (set to None)
- Raise clear errors for missing files or wrong column names

JSONL format:
```jsonl
{"input": "What is 2+2?", "expected_output": "4"}
{"input": "Name a planet", "expected_output": "Mars"}
```

CSV format:
```csv
input,expected_output
"What is 2+2?","4"
"Name a planet","Mars"
```

# DAY 5 — Built-in Eval Suites

## What is a suite?

A suite is a pre-built collection of (dataset + scorers) that you run in one line:

```python
from openeval.suites import hallucination
results = hallucination.run(my_model)
```

These are the showpiece feature. Someone tweets a screenshot of `openeval run --suite hallucination` and the beautiful terminal output. That's the viral moment.

Tell Claude:

- Scorer: `llm_judge` that checks if the model admitted uncertainty vs hallucinated

Example cases:
