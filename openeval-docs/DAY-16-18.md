# Days 16–18 — Comparison Benchmarks

## Goal
Run OpenEval, DeepEval, and Promptfoo on the same 3 tasks. Compare lines of code, setup time, and flexibility. Put the results in the README as a table. Factual, not trash-talk — just let the numbers speak.

This is the content that gets shared on r/MachineLearning and r/LocalLLaMA.

---

## Philosophy
Do NOT trash competitors. Be respectful and factual. The goal is to show a fair comparison where OpenEval wins on simplicity/DX. Let developers draw their own conclusions. If you trash-talk, people will push back and defend the other tools. If you're neutral and factual, developers trust you.

# DAY 16 — Benchmark Setup

## Step 1 — Install competitors for benchmarking

```bash
# In a separate venv for benchmarking only
pip install deepeval promptfoo
```

---

## Step 2 — Define 3 benchmark tasks

The same 3 tasks run on all 3 tools:

**Task A: Simple Q&A eval (20 cases)**
- Dataset: 20 basic factual Q&A pairs
- Scorer: exact match
- Measure: lines of code to set up, time to run

**Task B: Custom scorer (hallucination check)**
- Dataset: 15 hallucination test cases  
- Scorer: custom function that checks if model admitted uncertainty
- Measure: lines of code to write the custom scorer

**Task C: Multi-model comparison (10 cases)**
- Same dataset on 2 different models
- Measure: how many lines of code to compare models
