# Days 13–15 — Documentation Site + 8 Examples

## Goal
Build a beautiful MkDocs Material documentation site and 8 copy-paste-runnable example scripts. Docs are half the reason projects go viral. Bad docs = ignored project. Great docs = developers share the link.

---

## Philosophy for these 3 days
Every page of your docs should answer ONE question a developer is actually asking. Write like you're answering a Stack Overflow question, not writing a textbook.

## Step 7 — Deploy docs to GitHub Pages

Ask Claude: **"Write .github/workflows/docs.yml — GitHub Actions workflow to deploy MkDocs to GitHub Pages"**

```yaml
name: Deploy docs
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pip install mkdocs-material mkdocstrings[python]
      - run: mkdocs gh-deploy --force
```
